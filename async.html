Chapter 04

Async JavaScript

JavaScript is single-threaded. Async programming lets us do many things at once without blocking.

The Event Loop

The event loop is simple. It is a loop that checks:

  1. Is the call stack empty?
  2. If yes, push the oldest task from the microtask queue.
  3. If the microtask queue is empty, push one task from the macrotask queue.
  4. Repeat.
// Synchronous
console.log("1");

// Macrotask
setTimeout(() => console.log("2"), 0);

// Microtask
Promise.resolve().then(() => console.log("3"));

// Synchronous
console.log("4");

// Output: 1, 4, 3, 2
// Microtasks (Promises) run BEFORE macrotasks (setTimeout)
💡 Memory Trick

Microtasks are like VIPs. They always cut in line before regular (macro) tasks. If you keep adding microtasks, macrotasks starve.

Callbacks

A callback is a function passed into another function to run later. 

function fetchData(callback) {
  setTimeout(() => {
    callback("data");
  }, 1000);
}

fetchData((result) => {
  console.log(result); // "data"
});

Callback Hell

getData(function(a) {
  getMoreData(a, function(b) {
    getMoreData(b, function(c) {
      getMoreData(c, function(d) {
        console.log(d); // Deep nesting = hard to read
      });
    });
  });
});

Promises

A Promise is an object representing a future value. It has three states: pending, fulfilled, or rejected. 

const promise = new Promise((resolve, reject) => {
  const success = true;

  if (success) {
    resolve("It worked!");
  } else {
    reject(new Error("It failed"));
  }
});

promise
  .then(value => console.log(value))   // "It worked!"
  .catch(err => console.error(err))    // Runs on reject
  .finally(() => console.log("Done")); // Always runs

Promise.all

Wait for all promises. If one fails, everything fails.

const urls = ['/api/1', '/api/2', '/api/3'];
const promises = urls.map(url => fetch(url));

const results = await Promise.all(promises);

Promise.allSettled

Wait for all promises. Never fails. Returns status and value/reason for each. 

const results = await Promise.allSettled([
  Promise.resolve("ok"),
  Promise.reject("fail")
]);
// [{status:"fulfilled", value:"ok"}, {status:"rejected", reason:"fail"}]

Promise.race

Returns the first settled promise (fastest wins).

const winner = await Promise.race([
  fetch('/api/fast'),
  new Promise((_, reject) =>
    setTimeout(() => reject(new Error("Timeout")), 5000)
  )
]);

Async / Await

async makes a function return a Promise. await pauses the function until the Promise settles. 

async function getUser(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    if (!response.ok) throw new Error("HTTP error");
    return await response.json();
  } catch (err) {
    console.error("Fetch failed:", err);
    return null;
  }
}

Top-Level Await

Modern JS allows await at the top level of ES modules. 

// main.js (ES Module)
const data = await fetch('/api/config');
export const config = await data.json();

Parallel vs Sequential

Be careful. await inside a loop runs sequentially.

// SEQUENTIAL (slow)
for (const id of ids) {
  await fetchUser(id); // Waits for each one
}

// PARALLEL (fast)
const promises = ids.map(id => fetchUser(id));
const users = await Promise.all(promises);

// CONTROLLED PARALLEL (batch of 3)
async function batchFetch(ids, batchSize = 3) {
  const results = [];
  for (let i = 0; i < ids.length; i += batchSize) {
    const batch = ids.slice(i, i + batchSize);
    const batchResults = await Promise.all(
      batch.map(id => fetchUser(id))
    );
    results.push(...batchResults);
  }
  return results;
}
⚠️ Interview Trap

What is the output of: for (var i = 0; i < 3; i++) { setTimeout(() => console.log(i), 0); }? It prints 3, 3, 3. Use let or an IIFE to capture the current value.
