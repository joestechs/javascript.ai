Chapter 06

DOM & Events

The Document Object Model (DOM) is the tree of HTML elements that JavaScript can read and change.

Selecting Elements

// Single element
document.getElementById('app');
document.querySelector('.card');        // First match
document.querySelector('[data-id="42"]'); // Attribute selector

// Multiple elements
document.getElementsByClassName('item'); // Live HTMLCollection
document.getElementsByTagName('div');     // Live HTMLCollection
document.querySelectorAll('.item');        // Static NodeList
💡 Key Difference

getElementsBy* returns a live collection. If the DOM changes, the collection updates automatically. querySelectorAll returns a static snapshot.

Modifying the DOM

const box = document.createElement('div');
box.className = 'box';
box.textContent = 'Hello';
box.setAttribute('data-id', '1');

// Insert
parent.appendChild(box);           // At the end
parent.prepend(box);               // At the start
parent.insertBefore(box, sibling); // Before a specific node

// Modern: insertAdjacentHTML / Element
parent.insertAdjacentHTML('beforeend', 'New');

// Remove
box.remove(); // Modern
parent.removeChild(box); // Legacy

innerHTML vs textContent vs innerText

Property Parses HTML? Triggers reflow? Security risk?
innerHTML Yes Yes Yes (XSS)
textContent No No No
innerText No Yes No

Event Handling

const btn = document.querySelector('#submit');

// Method 1: Inline (bad practice)
// 

// Method 2: Property (only one handler)
btn.onclick = function() { console.log('clicked'); };

// Method 3: addEventListener (best practice)
btn.addEventListener('click', handleClick);
btn.addEventListener('click', trackAnalytics); // Multiple handlers allowed

function handleClick(event) {
  event.preventDefault();   // Stop default action
  event.stopPropagation();  // Stop bubbling
  console.log(event.target); // The element that triggered the event
  console.log(event.currentTarget); // The element with the listener
}

Event Phases

  1. Capturing — Event travels from document down to the target.
  2. Target — Event reaches the target element.
  3. Bubbling — Event travels back up from target to document. 
// Use capture phase (rarely needed)
element.addEventListener('click', handler, true);

// Stop bubbling
event.stopPropagation();

// Stop everything on this event
event.stopImmediatePropagation();

Event Delegation

Attach one listener to a parent instead of many listeners to children. Efficient and handles dynamically added elements. 

// Instead of adding a listener to every button...
const list = document.querySelector('#todo-list');

list.addEventListener('click', (e) => {
  if (e.target.matches('.delete-btn')) {
    e.target.closest('li').remove();
  }
  if (e.target.matches('.edit-btn')) {
    enterEditMode(e.target);
  }
});

DOM Performance Tips

// BAD: Touching the DOM in a loop causes many reflows
for (let i = 0; i < 1000; i++) {
  document.body.innerHTML += `
${i}
`; // 1000 reflows!
}

// GOOD: Use DocumentFragment
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const div = document.createElement('div');
  div.textContent = i;
  fragment.appendChild(div);
}
document.body.appendChild(fragment); // 1 reflow

// GOOD: Use requestAnimationFrame for animations
function animate() {
  element.style.transform = `translateX(${x}px)`;
  x += 2;
  if (x < 300) requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
