Chapter 09

Frameworks & Ecosystem

Frameworks help you build apps faster. But you must understand vanilla JavaScript first.

React

A library for building UIs with components. Uses a virtual DOM.

// Functional Component with Hooks
import { useState, useEffect } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;
  }, [count]);

  return (
    <button onClick={() => setCount(c => c + 1)}>
      Clicked {count} times
    </button>
  );
}

Key React Concepts

  • JSX — Syntax extension that looks like HTML.
  • Components — Reusable UI building blocks.
  • Props — Read-only data passed from parent to child.
  • State — Mutable data managed within a component.
  • Hooks — Functions like useState, useEffect, useContext.
  • Virtual DOM — In-memory representation of the real DOM.

Vue

A progressive framework. Easy to adopt incrementally.

<script setup>
import { ref, computed } from 'vue';

const count = ref(0);
const doubled = computed(() => count.value * 2);

function increment() {
  count.value++;
}
</script>

<template>
  <button @click="increment">{{ count }}</button>
  <p>Doubled: {{ doubled }}</p>
</template>

Angular

A full-featured framework by Google. Uses TypeScript by default.

  • Components — Class + Template + Styles.
  • Dependency Injection — Built-in IoC container.
  • RxJS — Reactive programming with Observables.
  • Directives — *ngIf, *ngFor, custom attribute directives.

Svelte

A compiler, not a runtime library. Converts components to efficient vanilla JS. 

<script>
  let count = 0;
  $: doubled = count * 2; // Reactive statement
</script>

<button on:click={() => count++}>
  Count: {count}
</button>
<p>Doubled: {doubled}</p>

Node.js

JavaScript on the server. Event-driven, non-blocking I/O.

// Simple HTTP server
const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello World\n');
});

server.listen(3000);

// Modern: Express.js
const express = require('express');
const app = express();

app.get('/', (req, res) => res.json({ message: 'Hello' }));
app.listen(3000);
