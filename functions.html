Chapter 02

Functions & Scope

Functions are the heart of JavaScript. They are objects. They create scope. They enable closures.

Three Ways to Define a Function

1. Function Declaration

function greet(name) {
  return `Hello, ${name}`;
}

// Hoisted: you can call it before its definition
console.log(greet("Ada"));

2. Function Expression

const greet = function(name) {
  return `Hello, ${name}`;
};

// NOT hoisted. Must be defined before use.

3. Arrow Function

const greet = (name) => `Hello, ${name}`;

// Key differences from regular functions:
// 1. No 'this' binding (inherits from parent scope)
// 2. No 'arguments' object
// 3. Cannot be used as a constructor

Scope and the Scope Chain

Scope answers one question: Where can I access this variable? 

const global = "I am global";

function outer() {
  const outerVar = "I am outer";
  
  function inner() {
    const innerVar = "I am inner";
    console.log(global);   // ✓ Found in global scope
    console.log(outerVar); // ✓ Found in outer scope
    console.log(innerVar); // ✓ Found in inner scope
  }
  
  inner();
}

outer();

Lexical Scoping

JavaScript uses lexical (static) scoping. A function's scope is determined by where it is written, not where it is called.

Closures

A closure is a function that remembers its outer variables even when the outer function has finished. 

function makeCounter() {
  let count = 0;
  
  return function() {
    return ++count; // 'count' is remembered via closure
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
💡 Interview Tip

Closures are used in: data privacy, factory functions, partial application, and maintaining state in async callbacks.

Closure in a Loop (Classic Pitfall)

// WRONG: All buttons alert "Button 5"
for (var i = 0; i < 5; i++) {
  setTimeout(() => alert("Button " + i), 100);
}

// FIX 1: Use let (block-scoped)
for (let i = 0; i < 5; i++) {
  setTimeout(() => alert("Button " + i), 100);
}

// FIX 2: Use an IIFE to capture i
for (var i = 0; i < 5; i++) {
  (function(capturedI) {
    setTimeout(() => alert("Button " + capturedI), 100);
  })(i);
}

The 'this' Keyword

The value of this depends on how a function is called. Not where it is written.

Context this refers to
Global scope (non-strict) window (browser) or global (Node)
Global scope (strict mode) undefined
Object method The object before the dot
Constructor (new) The new instance
Event handler The DOM element that fired the event
Arrow function this from the enclosing (parent) scope
call / apply / bind The first argument passed 
const user = {
  name: "Ada",
  greet() {
    console.log("Hi, " + this.name);
  },
  arrowGreet: () => {
    console.log("Hi, " + this.name); // 'this' is window, not user
  }
};

user.greet();      // "Hi, Ada"
user.arrowGreet(); // "Hi, undefined" (or window.name)

Explicit Binding

function introduce() {
  console.log("I am " + this.name);
}

const person = { name: "Grace" };

introduce.call(person);   // "I am Grace"  (calls immediately)
introduce.apply(person);  // "I am Grace"  (calls immediately, array args)

const bound = introduce.bind(person); // returns a new function
bound(); // "I am Grace"

IIFE (Immediately Invoked Function Expression)

(function() {
  const privateVar = "secret";
  console.log("Runs once!");
})();

// Modern alternative: just use block scope
{
  const privateVar = "secret";
}
