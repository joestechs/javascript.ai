Chapter 01

JavaScript Fundamentals

We start with the building blocks. Every line of JavaScript uses these ideas. Master them first.

Variables: var, let, and const

JavaScript has three ways to declare a variable. Each behaves differently.

Keyword Scope Can Reassign? Hoisted?
var Function Yes Yes (initialized undefined)
let Block Yes Yes (not initialized)
const Block No Yes (not initialized) 
// var is function-scoped
function example() {
  if (true) {
    var x = 10;
  }
  console.log(x); // 10 — x escapes the block
}

// let is block-scoped
function example2() {
  if (true) {
    let y = 10;
  }
  // console.log(y); // ReferenceError: y is not defined
}
⚠️ Common Mistake

Never use var in modern code. Use const by default. Use let only when you must reassign.

Types and Type Coercion

JavaScript has 8 data types. 7 are primitive. 1 is structural.

The 8 Types

  1. string — Text data
  2. number — Integers and floats (including Infinity, NaN)
  3. bigint — Arbitrary-precision integers (e.g., 123n)
  4. boolean — true or false
  5. undefined — A variable with no value
  6. null — Intentional absence of value
  7. symbol — Unique identifier
  8. object — Arrays, functions, dates, regex, and plain objects

typeof Quirks

typeof "hello";     // "string"
typeof 42;          // "number"
typeof 42n;         // "bigint"
typeof true;        // "boolean"
typeof undefined;   // "undefined"
typeof null;        // "object"  ← BUG from 1995. Never fixed.
typeof {};          // "object"
typeof [];          // "object"  ← Arrays are objects
typeof function(){}; // "function" ← Special treatment

Truthiness and Falsiness

These 7 values are always falsy. Everything else is truthy.

if ("" || 0 || -0 || 0n || null || undefined || NaN) {
  // This block NEVER runs
}

Coercion Rules

"5" + 3;     // "53"  (number becomes string)
"5" - 3;     // 2     (string becomes number)
"5" * "2";   // 10    (both become number)
true + true; // 2     (true coerces to 1)
"" == false; // true  (both coerced to 0)
"" === false; // false (different types)
✅ Best Practice

Always use === and !==. Avoid == unless you fully understand the Abstract Equality Comparison Algorithm.

Operators Deep Dive

Logical Operators

&& and || do not return booleans. They return one of the operands. 

const a = "" || "default";  // "default"
const b = "user" && "ok";    // "ok"
const c = null ?? "fallback"; // "fallback"  ← Nullish Coalescing

Optional Chaining

const user = { profile: null };
const name = user.profile?.name; // undefined (no error)

Control Flow

for...of vs for...in

const arr = ['a', 'b'];
const obj = { x: 1, y: 2 };

// for...of → values (iterables)
for (const val of arr) console.log(val); // a, b

// for...in → keys (enumerable property names)
for (const key in obj) console.log(key); // x, y

// NEVER use for...in on arrays. It iterates over ALL enumerable keys including prototypes.

Switch Statement

switch (status) {
  case 200:
  case 201:
    console.log("Success");
    break;
  case 404:
    console.log("Not found");
    break;
  default:
    console.log("Unknown");
}

Strict Mode

Strict mode removes silent errors and fixes mistakes that make engines hard to optimize. 

"use strict";

x = 3.14; // ReferenceError: x is not defined
delete Object.prototype; // TypeError
