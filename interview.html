Basics

== checks value with type coercion. === checks value AND type without coercion. Always use === to avoid unexpected conversions like 0 == "" being true.

"", 0, -0, 0n, null, undefined, NaN, and false. Everything else is truthy, including "0", [], and {}.

The TDZ is the period between entering a block scope and the actual declaration of a let or const variable. Accessing the variable during this time throws a ReferenceError.

var is function-scoped, hoisted, and can be redeclared. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned (but object properties can still change).

Functions & Scope

A closure is a function that remembers variables from its outer scope even after the outer function has finished executing. Closures enable data privacy, factory functions, and maintaining state in callbacks.

The value of this depends on how a function is called: global object (non-strict), undefined (strict), the object (method), the instance (constructor), the DOM element (event handler), or the parent scope (arrow function).

call invokes a function with a given this and comma-separated arguments. apply does the same but takes an array of arguments. bind returns a new function with this permanently bound, without invoking it immediately.

An Immediately Invoked Function Expression is a function that runs as soon as it is defined. It creates a private scope, preventing variables from polluting the global namespace. Modern alternative: use block scope with {}.

Async JavaScript

The event loop is a loop that checks if the call stack is empty. If so, it pushes tasks from the microtask queue (Promises, queueMicrotask) first, then from the macrotask queue (setTimeout, setInterval, I/O). This allows JavaScript to handle async operations on a single thread.

Microtasks have higher priority. After the current synchronous code finishes, ALL microtasks run before the next macrotask. Examples: Promises, queueMicrotask. Macrotasks: setTimeout, setInterval, DOM events.

Output: 1, 4, 3, 2. 1 and 4 are synchronous. 3 is a microtask (Promise) and runs before 2, which is a macrotask (setTimeout).

Promise.all fails fast: if any promise rejects, the entire result rejects. Promise.allSettled waits for all promises regardless of outcome and returns an array of objects with status and either value or reason.

Objects & Classes

Object.create(proto) creates an object with a specified prototype directly. A constructor function uses new to create an instance, sets this to the new object, and links its prototype automatically.

Every object has an internal link to another object called its prototype. When you access a property, JavaScript walks up this chain until it finds the property or reaches null. This is how inheritance works in JS.

Private fields use the # prefix. They are truly private: not accessible outside the class, not enumerable, and not inherited. This is a modern ES2022 feature.

DOM & Browser

Event delegation attaches a single event listener to a parent element instead of many listeners to child elements. Events bubble up, so the parent can handle them. This is memory-efficient and works for dynamically added elements.

event.target is the element that actually triggered the event. event.currentTarget is the element that has the event listener attached. In delegation, they are often different.

Use DocumentFragment to batch insertions, minimize reflows by batching style changes, use requestAnimationFrame for animations, delegate events, and avoid reading layout properties (like offsetHeight) in loops because they force synchronous reflow.

Advanced

A Proxy is an object that wraps another object and intercepts operations like getting, setting, and deleting properties. It enables validation, logging, and reactive systems.

Map allows any key type and keeps strong references. WeakMap only allows objects as keys and holds weak references, allowing garbage collection when no other references exist. WeakMaps are not iterable.

Generators are useful for lazy evaluation, infinite sequences, async flow control (before async/await), and implementing custom iterables. They pause execution with yield and resume with next().

Array.prototype.myMap = function(callback) {
  const result = [];
  for (let i = 0; i < this.length; i++) {
    result.push(callback(this[i], i, this));
  }
  return result;
};
function debounce(fn, delay) {
  let timer;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
function deepClone(obj, hash = new WeakMap()) {
  if (Object(obj) !== obj) return obj;
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);
  if (hash.has(obj)) return hash.get(obj);

  const result = Array.isArray(obj) ? [] : {};
  hash.set(obj, result);

  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      result[key] = deepClone(obj[key], hash);
    }
  }
  return result;
}
function flatten(arr) {
  return arr.reduce((acc, val) =>
    acc.concat(Array.isArray(val) ? flatten(val) : val), []);
}
