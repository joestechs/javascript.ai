Chapter 05

ESM & Modules

JavaScript modules let you split code into reusable files. There are two main systems: CommonJS (Node) and ES Modules (modern standard).

ES Modules (ESM)

ESM is the official standard. It uses static imports, which enables tree-shaking and better tooling.

Named Exports

// math.js
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

// app.js
import { PI, add } from './math.js';
console.log(add(2, 3)); // 5

Default Exports

// logger.js
export default function log(msg) {
  console.log(`[LOG] ${msg}`);
}

// app.js
import log from './logger.js';
// You can rename default imports freely
import myLog from './logger.js';

Mixed Exports

// utils.js
export const helper = () => {};
export const config = {};
export default class Utils {}

// app.js
import Utils, { helper, config } from './utils.js';
import * as utils from './utils.js';

CommonJS (CJS)

Node.js originally used CommonJS. It is still widely used but ESM is the future. 

// math.cjs
const PI = 3.14159;

function add(a, b) {
  return a + b;
}

module.exports = { PI, add };

// app.cjs
const { PI, add } = require('./math.cjs');
Feature ESM CommonJS
Syntax import/export require/module.exports
Loading Static (parse time) Dynamic (runtime)
Tree Shaking Yes No
Top-level await Yes No
Browser native Yes No

Dynamic Import

Load modules on demand. Returns a Promise.

async function loadChart() {
  const { default: Chart } = await import('./chart.js');
  const chart = new Chart();
  chart.render();
}

// Conditional loading
if (userPrefersDark) {
  const theme = await import('./dark-theme.js');
  theme.apply();
}

Tree Shaking

Tree shaking removes unused exports at build time. It only works with ESM because imports are static. 

// library.js — exports 100 functions
export function a() {}
export function b() {}
// ... 98 more

// app.js — only imports 'a'
import { a } from './library.js';

// With tree shaking, only 'a' ends up in the bundle.
// 'b' and the rest are removed.

Circular Dependencies

When module A imports B, and B imports A. ESM handles this better than CJS. 

// a.js
import { b } from './b.js';
export const a = 'A';
console.log(b); // undefined (b has not finished evaluating yet)

// b.js
import { a } from './a.js';
export const b = 'B';
console.log(a); // "A" (a was already declared)
⚠️ Avoid Circular Dependencies

Refactor shared code into a third module. Circular deps create hard-to-debug initialization order bugs.
