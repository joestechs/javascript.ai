Chapter 03

Objects & Classes

JavaScript is a prototype-based language. Classes are syntactic sugar over prototypes.

Object Creation Patterns

Object Literal

const user = {
  name: "Ada",
  age: 30,
  greet() {
    return "Hello";
  }
};

// Computed property names
const key = "id";
const item = { [key]: 123 }; // { id: 123 }

Object Methods

Object.keys(user);    // ["name", "age", "greet"]
Object.values(user);  // ["Ada", 30, ƒ]
Object.entries(user); // [["name","Ada"], ["age",30], ...]

// Check property existence
"name" in user;        // true
user.hasOwnProperty("name"); // true (ignores prototype chain)

Prototypes

Every object has an internal link to another object called its prototype. When you access a property, JavaScript looks up the chain. 

const animal = {
  eats: true,
  walk() {
    console.log("walking");
  }
};

const rabbit = {
  jumps: true
};

// Set prototype
Object.setPrototypeOf(rabbit, animal);

rabbit.walk();   // "walking" — found on animal
rabbit.eats;     // true

Constructor Functions (Old Style)

function Animal(name) {
  this.name = name;
}

Animal.prototype.speak = function() {
  console.log("${this.name} makes a sound");
};

const dog = new Animal("Rex");
dog.speak(); // "Rex makes a sound"

ES6 Classes

Classes are cleaner syntax. Under the hood, they still use prototypes. 

class Animal {
  constructor(name) {
    this.name = name;
  }
  
  speak() {
    console.log(`${this.name} makes a sound`);
  }
  
  // Static method — belongs to the class, not instances
  static isAnimal(obj) {
    return obj instanceof Animal;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name); // Must call super() before using 'this'
    this.breed = breed;
  }
  
  speak() {
    super.speak(); // Call parent method
    console.log(`${this.name} barks`);
  }
}

Private Class Fields (Modern)

class BankAccount {
  #balance = 0; // Private field
  
  deposit(amount) {
    if (amount > 0) this.#balance += amount;
  }
  
  getBalance() {
    return this.#balance;
  }
}

const acc = new BankAccount();
acc.deposit(100);
console.log(acc.getBalance()); // 100
console.log(acc.#balance);     // SyntaxError: Private field must be declared
⚠️ Important

Private fields (#) are truly private. They are not accessible from outside the class or even from subclasses. Use protected-like patterns with symbols or closures if you need inheritance access.
